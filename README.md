# 신호 탐지기 (Signal Detector)

주변의 **BLE / 블루투스 / Wi-Fi** 신호를 탐색해 새로 나타난 신호를 표시하고,
선택한 신호의 세기를 추적해 **가까워지는지·멀어지는지**, **어느 방향인지**를 알려주는 안드로이드 앱입니다.

## APK 만드는 방법 (셋 중 하나)

### A. GitHub Actions로 자동 빌드 (설치 없이 가장 쉬움)
1. GitHub에서 새 저장소를 만들고 이 폴더 전체를 업로드(push)합니다.
2. 저장소의 **Actions** 탭 → `Build APK` 실행이 끝나면 **Artifacts**의 `signal-detector-apk`를 내려받습니다.
3. 압축을 풀면 `app-debug.apk`가 나옵니다.

### B. Android Studio
1. Android Studio에서 이 폴더를 엽니다 (`File > Open`). 처음 열면 Gradle 동기화가 자동으로 진행됩니다.
   (AGP/Gradle 업그레이드를 제안하면 수락해도 됩니다.)
2. `Build > Build Bundle(s) / APK(s) > Build APK(s)`
3. 완료 알림의 `locate`를 누르면 `app/build/outputs/apk/debug/app-debug.apk`가 있습니다.

### C. 명령줄 (JDK 17 + Android SDK가 있는 PC)
```
./gradlew assembleDebug
```

## 폰에 설치
APK를 폰으로 옮겨 실행합니다. "출처를 알 수 없는 앱 설치"를 한 번 허용해야 합니다.
처음 실행하면 **근처 기기 / 위치 권한**을 묻습니다. 허용하고, **위치(GPS) 서비스와 블루투스, Wi-Fi를 켜 두세요**
(안드로이드는 위치가 꺼져 있으면 주변 신호 목록을 주지 않습니다).

## 사용법
1. **탐색 시작** → 처음 15초는 기준 수집 구간입니다. 이때 보인 신호는 "기존 신호"로 처리됩니다.
2. 그 이후 처음 나타난 신호에는 **NEW** 표시가 붙고 목록 맨 위로 올라옵니다. ("새 신호만 표시" 스위치로 걸러 볼 수 있음)
   - **기준 재설정**: 지금 보이는 신호를 모두 기존 신호로 처리
   - **목록 비우기**: 목록과 기준을 새로 시작
3. 목록에서 신호를 누르면 **추적 화면**이 열립니다.
   - 세기(dBm)와 최근 60초 그래프
   - ▲ 가까워지는 중 / ▼ 멀어지는 중 / ● 변화 없음 (최근 세기 변화율 기준)
   - 대략적인 거리와 근접도
   - **방향**: 휴대폰을 몸에서 조금 떨어뜨려 들고 제자리에서 천천히 한 바퀴 돌면, 방향별 세기를 모아 신호가 오는 쪽을 화살표로 알려줍니다.
     화면 위쪽이 휴대폰이 향한 방향이고, 화살표가 위쪽을 가리키면 그쪽으로 가면 됩니다.

## 알아둘 점 (한계)
- **BLE가 가장 정확하게 추적됩니다.** 클래식 블루투스와 Wi-Fi는 측정 간격이 길어(수 초~수십 초) 추세·방향이 느리게 반영됩니다.
  안드로이드 9 이상은 Wi-Fi 스캔 횟수를 제한하므로, 더 자주 갱신하려면 개발자 옵션의 "Wi-Fi 스캔 제한"을 끄세요.
- 거리와 방향은 **전파 세기로 추정한 값**이라 벽, 사람 몸, 반사 때문에 오차가 큽니다. 몇 m 단위의 "가까움/멀음" 판단용으로 보세요.
- 이 앱은 신호의 **존재와 세기**만 봅니다. 통신 내용은 알 수 없고, 그 신호가 부정행위에 쓰이는지도 판단할 수 없습니다.
  시험장에 원래 있던 공유기, 감독관 기기, 다른 사람의 기기와도 구분되지 않으므로 **참고 자료로만** 사용하세요.
- 일부 기기(특히 아이폰 등)는 블루투스 주소를 주기적으로 바꿔서, 같은 기기가 "새 신호"로 다시 잡힐 수 있습니다.
- 처음 실행할 때 나침반이 부정확하면 휴대폰을 8자 모양으로 흔들어 보정하세요.

## 구조
```
app/src/main/java/com/example/signaldetector/
  MainActivity.kt    화면(목록/추적), 권한, 센서
  SignalScanner.kt   BLE·클래식 블루투스·Wi-Fi 스캔
  SignalTracker.kt   세기 평활, 추세, 거리, 방향 추정
  Models.kt          신호 모델, 새 신호 판정(기준 구간)
  Views.kt           나침반 뷰, 그래프 뷰
```
